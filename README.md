# 👁️ Don't Play Game (DOORS Text Edition)

> *"💧 Водный Свет помнит каждую твою ошибку..."*

**Don't Play Game** — это текстовый консольный хоррор на Python, созданный по мотивам популярной игры **DOORS** на платформе Roblox.

Пройди сквозь тёмные коридоры Отеля, спустись в бесконечную лестничную шахту и постарайся выжить в изолированных комнатах, где за каждым шагом следят опасные сущности.

---

## 🎮 Особенности игры

* **🏛️ 3 уникальные локации:**
  * 🏨 **The Hotel** — классические Комнаты 1–100 с загадками, ивентами и сущностями.
  * 🚪 **The Rooms** — секретный подэтаж (A-001 – A-1000) с усиленной атмосферой и особыми правилами выживания.
  * 🪜 **The Stairwell** — опасный бесконечный спуск вниз.
* **👹 Опасные Сущности:**
  * **Отель и Rooms:** Драш, Рейс, Сик, A-60, A-90, A-120.
  * **The Stairwell:** Краш, Браш и загадочный Блич.
  * **Архитектор:** Водный Свет (подводит итоги и ведет учет твоих смертей).
* **🏪 Магазин Джеффа:** Покупка фонариков, отмычек, зажигалок и таблеток за найденные монеты.
* **🏆 Система Бейджей:** Уникальные достижения за особые заслуги и победы.
* **💀 Статистика:** Отслеживание смертей с сохранением прогресса в `stats.json`.
* **🔊 Звуковое сопровождение:** Атмосферные звуковые эффекты на встроенном движке Windows (`winsound`).
